# John Wolf Portfolio — Cinematic Hero Starter

A Vite + React portfolio starter with:

- A continuously looping, muted, inline background video
- A permanent solid-black foundation beneath the video
- GSAP entrance and scroll motion
- Lenis smooth scrolling
- Responsive navigation and mobile layout
- Glass expertise cards with pointer-reactive depth
- A temporary black transition stage for the future second scene

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The supplied background video lives at `public/assets/hero-neon.mp4`.
